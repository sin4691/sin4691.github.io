UNDER HALL

PROJECT 02 · 팀 프로젝트 · 팀장

Under Hall

4인 팀 프로젝트 팀장

개요

1인 플레이 로그라이트(Roguelite) 장르 게임을 만든 4인 팀 프로젝트입니다. 팀원 전원이 Git과 협업 프로젝트 경험이 처음이었습니다.

담당 역할

팀장으로서 기획 방향 확립과 최종 의사결정, 일정 관리, 발표를 총괄했습니다. 개발 측면에서는 UI 시스템 프로그래밍, 맵(레벨) 배치, 게임 데이터 값 총괄을 직접 담당했고, 팀원 전원이 Git이 처음이었던 만큼 Git 협업 프로세스를 정립하고 관리하는 역할도 맡았습니다.

트러블슈팅

CASE 1 — Git 인코딩 문제

문제 · 팀원들의 코드가 실제로는 바뀐 내용이 없는데도 Git에서 계속 변경(diff)으로 감지되는 문제가 반복됐습니다.

원인 · 팀원마다 에디터의 파일 인코딩 설정이 달라 저장할 때마다 인코딩이 미묘하게 달라졌습니다.

해결 · Visual Studio 인코딩을 UTF-8로 통일하고, .editorconfig와 .gitattributes로 인코딩/줄바꿈 규칙을 강제해 문제를 해결했습니다.

CASE 2 — 빌드 버전 크래시

문제 · 에디터에서는 정상이었지만, 실제 빌드 버전에서 한글 UI를 출력할 때 앱이 강제 종료(크래시)됐습니다.

원인 · 한글 UI에 TextMeshPro(TMP) 폰트를 Dynamic 모드로 사용하고 있었고, 빌드 환경에서 필요한 글리프를 런타임에 생성하는 과정에서 크래시가 발생했습니다.

해결 · 한글 완성형 2,350자를 미리 구운 Static 폰트로 교체해 런타임 글리프 생성을 없애 크래시를 제거했습니다.

DEADLINE

PROJECT 03 · 개인 프로젝트

DeadLine

1인 개발

개요

게임 개발을 처음 배우기 시작했을 때 기획부터 구현까지 혼자 진행한 공포(Horror) 장르 게임입니다.

핵심 구현 — 은신(발각) 시스템

몬스터에 콜라이더 기반으로 3단계 감지 범위(큰 소리 · 중간 소리 · 작은 소리)를 설정했습니다. 플레이어의 이동 상태(달리기 · 걷기 · 앉아서 걷기)마다 서로 다른 소음 값을 부여하고, 값이 변할 때마다 이를 읽어 현재 위치한 감지 범위의 허용 수치를 넘으면 발각되도록 구현했습니다. 상시 레이캐스트 대신 콜라이더 기반 판정을 사용해 연산 부담을 줄였습니다.

핵심 구현 — AI 추격 시스템

소리로 발각되면 그 위치를 실시간으로 계속 갱신하고, 몬스터가 최신 발각 위치까지 이동하도록 구현했습니다. 도착 후에는 주변을 둘러보는 Idle 상태로 전환해 재탐색하도록 만들어, 플레이어를 놓쳤을 때도 자연스럽게 순찰로 이어지게 했습니다.
